## Overview

As autonomous coding agents become capable of handling increasingly long-horizon tasks, they have started to show the potential of completing **end-to-end software development**. However, existing benchmarks remain confined to structurally simplified, single-stack applications, and therefore fail to capture the heterogeneous environments, full-stack orchestration, and system-level complexity of real **enterprise SaaS** systems.

To fill this gap, we introduce **SaaSBench**, the first benchmark designed to explore the boundaries of AI agents in enterprise SaaS engineering:

- **30 complex tasks** across **6 SaaS domains**, with **5,370 validation nodes**
- **8 programming languages**, **6 databases**, and **13 frameworks**, meticulously mirroring real-world software heterogeneity
- A **dependency-aware hybrid evaluation paradigm**, tailored for long-horizon systems with multi-component coupling — enabling fine-grained, reproducible assessment
